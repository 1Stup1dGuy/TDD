# Dicebound Galaxy

Dicebound Galaxy is a browser-based space dice RPG about exploring star sectors, rolling combat dice, recruiting aliens, upgrading dice cores, and surviving reactor overloads.

This project is an original game inspired only by broad, non-copyrightable gameplay ideas: dice-based RPG combat, alien collecting, sector progression, and push-your-luck risk/reward mechanics.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Core Loop

Explore sector → battle aliens → roll dice → risk overload → fire attack → recruit aliens → choose reward → upgrade party → defeat boss → next sector.
